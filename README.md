# Intro to EEG Analysis

UChicago Neurotech's first-meeting tutorial: what EEG is, references (CAR and bipolar), the FFT, notch and band-pass filtering, eye artifacts, and alpha waves. Uses [MNE-Python](https://mne.tools) on public datasets.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/UChicago-Neurotech/eeg-tutorial/blob/main/intro_eeg.ipynb)

Click the badge, then **Runtime → Run all**. No setup is needed. You get your own copy, so edit freely.

## Files

- `intro_eeg.ipynb`: the attendee notebook, with no outputs
- `intro_eeg_with_outputs.ipynb`: a pre-run copy for presenters or as a backup
- `build_notebook.py`: generates the notebook (`python build_notebook.py intro_eeg.ipynb`)

## Data

- [EEG Motor Movement/Imagery Dataset](https://physionet.org/content/eegmmidb/) (PhysioNet)
- [ERP CORE](https://erpinfo.org/erp-core) (Kappenman et al., 2021)
